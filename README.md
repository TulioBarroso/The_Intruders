# The_Intruders
Jogo criado no processing para a matéria de game engine.

1. baixe o processing https://processing.org ou https://github.com/processing/processing4/releases/download/processing-1313-4.5.2/processing-4.5.2-windows-x64-portable.zip
2. Com o processing aberto, baixe o repositorio do the intruders e execute o The_Intruders

Obs: Só é possivel executar o jogo com o processing aberto antes.
